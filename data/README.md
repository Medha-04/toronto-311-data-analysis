# Data

The Toronto 311 dataset is not included in this repository because of its file size.

The analysis uses Toronto 311 service request data provided through the City of Toronto's Open Data portal.

To reproduce the analysis:

1. Download the Toronto 311 dataset.
2. Place the CSV in this folder.
3. Rename it to `SR2026.csv`.
4. Run the notebook from the root of this repository.

The expected file path is:

`data/SR2026.csv`
